# VideoGetTool v0.4.0

发布日期：2026-08-25

v0.4.0 是 VideoGetTool 的重大版本更新，新增 **B 站（Bilibili）视频抓取与下载** 支持，使产品具备双平台内容获取能力。

## 新功能

| 编号 | 功能 | 说明 |
|---|---|---|
| 1 | B 站视频链接解析 | 支持 BV 号、av 号、短链（b23.tv）的自动识别与解析 |
| 2 | B 站视频信息展示 | 获取标题、UP 主、播放量、弹幕数、标签、发布时间等元数据 |
| 3 | B 站多 P 视频选择下载 | 支持分 P 视频的逐 P 选择和批量下载 |
| 4 | B 站 DASH 音视频合并 | 自动下载分离的音视频流并通过 ffmpeg 合并为完整 MP4 |
| 5 | B 站用户空间抓取 | 输入 UP 主空间链接，批量获取投稿列表 |
| 6 | B 站 Cookie 测试 | 在 B 站抓取页直接测试 Cookie 有效性 |
| 7 | 双平台架构 | 抖音与 B 站共用下载引擎、任务队列、进度推送 |
| 8 | B 站抓取页面 | 独立导航入口，专为 B 站优化的操作界面 |

## 技术改进

- 新增 **bilibili 爬虫模块**（crawlers/bilibili/）：WBI 签名、buvid3 指纹、链接解析、HTTP 客户端、视频解析、用户空间抓取
- 下载引擎 **DASH 合并支持**：自动检测音视频分离流，并发下载后通过 ffmpeg 流式合并（-c copy）
- 数据库 **Schema v4**：新增 bvid/cid/page/audio_url/dash_merged 字段
- 后端新增 **4 个 B 站 API 端点**：parse、playurl、fetch-space、cookie-test
- 测试套件扩展至 **734 项**（新增 79 项 B 站模块测试）

## 依赖变更

| 依赖 | 版本 | 协议 | 用途 |
|---|---|---|---|
| ffmpeg（运行时） | 可选 | GPL | DASH 音视频合并（用户自行安装或提供路径） |

## 已知限制

- B 站 1080P+ 高画质需要大会员 Cookie，工具不主动破解会员限制
- B 站番剧/影视下载暂不支持（版权保护严格）
- B 站直播录制暂不支持
- B 站弹幕下载与转换暂不支持
- B 站收藏夹/合集下载暂不支持（V2 规划）
- 前端 TypeScript 类型检查需要 `pnpm install && pnpm exec tsc --noEmit`（前端依赖安装后）
- 系统需要安装 ffmpeg 才能完成 B 站 DASH 视频的音频合并
